# 🐍 Python Project Mastery: De CLI a Arquitectura Backend

Un recorrido estructurado y progresivo a través del desarrollo de software con Python. 
Este repositorio documenta la construcción de proyectos modulares, escalables y orientados a buenas prácticas de ingeniería, comenzando desde aplicaciones de consola (CLI) hasta la implementación de APIs RESTful integradas con bases de datos relacionales orientadas a la gestión logística y administrativa.

## 🎯 Objetivo del Repositorio
Demostrar el dominio de Python y la evolución arquitectónica del código, aplicando principios de Clean Code, manejo eficiente de estructuras de datos y persistencia de información en entornos que resuelven requerimientos empresariales reales.

## 🚀 Roadmap de Proyectos

* **[✅] Nivel 1: Gestor de Tareas (CLI)**
  * **Conceptos:** Estructuras de datos en memoria (Listas y Diccionarios), Control de flujo, Funciones modulares, Manejo de excepciones (`try/except`).
  * **Estado:** Completado.

* **[⏳] Nivel 2: Analizador de Inventario (I/O Archivos)**
  * **Conceptos:** Persistencia de datos local, Manipulación y lectura de archivos CSV/JSON, Librerías estándar.
  * **Estado:** En planificación.

* **[⏳] Nivel 3: Extractor de Datos Financieros (Web Scraping)**
  * **Conceptos:** Peticiones HTTP, Parseo de HTML, Librerías de terceros (`requests`, `BeautifulSoup`).
  * **Estado:** En planificación.

* **[⏳] Nivel 4: Sistema de Gestión Logística Integrado**
  * **Conceptos:** Conexión y consultas a bases de datos (SQL Server / SQLite), Operaciones CRUD avanzadas, Sincronización de estructuras de tablas, Arquitectura MVC (Modelo-Vista-Controlador).
  * **Estado:** En planificación.

* **[⏳] Nivel 5: API RESTful Backend**
  * **Conceptos:** Desarrollo web backend (FastAPI/Flask), Endpoints para consumo de datos, Enrutamiento, JSON Responses.
  * **Estado:** En planificación.

## 🛠️ Stack Tecnológico y Habilidades
* **Lenguaje Core:** Python 3.x
* **Bases de Datos (Proyectado):** SQL Server, SQLite
* **Principios de Ingeniería aplicados:** 
  * Diseño de menús e interfaces de línea de comandos (CLI).
  * Modularidad y segmentación de responsabilidades (`__main__`).
  * Validación estricta de inputs del usuario.
